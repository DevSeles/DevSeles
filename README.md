# Olá, eu sou o DevSeles 👋

Desenvolvo produtos digitais com foco em resolver problemas reais de forma simples, organizada e sustentável.

Atualmente, estou construindo uma plataforma de gestão de obras para pequenas e médias construtoras. A proposta é unir a profundidade de um sistema de gestão à simplicidade necessária para quem trabalha no canteiro — do construtor mais tradicional ao gestor acostumado com tecnologia.

## No que estou trabalhando

- gestão de obras, custos, orçamento, compras e acompanhamento de campo;
- experiências simples para processos operacionais complexos;
- inteligência artificial aplicada à organização, análise e tomada de decisão;
- aplicações web e móveis com arquitetura preparada para crescer.

## Tecnologias

`Java 21` · `Spring Boot` · `PostgreSQL` · `React` · `TypeScript` · `React Native` · `Docker`

## Princípios que orientam meu trabalho

- simplicidade para o usuário, consistência por trás da interface;
- entregas pequenas, verificáveis e úteis;
- automação com supervisão humana;
- segurança, rastreabilidade e respeito aos dados;
- tecnologia como ferramenta — não como complicação.
